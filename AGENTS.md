Данный проект предназначен для ведения собственных заметок и гайдов, то есть является моей личной базой знаний.

При написании документов стоит придерживаться методологии [Diátaxis](https://diataxis.fr/)

В основном база будет содержать "How-to guides", то есть большая часть информации рассчитана на человека который уже что-то понимает и хочет добиться определенного результата.

Иногда будут встречаться "Reference" для установки четких правил, например: "как правильно форматировать исходный Java-код"
