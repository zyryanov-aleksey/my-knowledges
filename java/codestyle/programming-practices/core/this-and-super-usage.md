# Использование this и super

## this

this не должен использоваться без необходимости.

Правила:

- Не указывать `this` при обычном обращении к полям и методам экземпляра.
- Использовать `this` для разрешения конфликта имён.
- Использовать `this`, когда требуется ссылка на текущий объект.
- Использовать `this(...)` для делегирования другому конструктору того же класса.

## super

super должен явно выражать намерение обратиться к реализации родительского типа.

Правила:

- Необходимо использовать `super` для явного обращения к реализации метода суперкласса.
- Необходимо использовать `super(...)` для явного вызова конструктора суперкласса.
