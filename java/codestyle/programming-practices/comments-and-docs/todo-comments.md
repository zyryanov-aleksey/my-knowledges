# Комментарии `TODO`

Начинайте `TODO` с ссылки или идентификатора задачи и после `-` кратко указывайте
условие удаления. Не используйте имя сотрудника или команды вместо задачи.

Правильное использование TODO:

```java
// TODO: DITBIIG-13709 - Оптимизировать доступ к БД, добавить индексы

// или:

// TODO: PROJECT-12345 - Обработать какую-то внутреннюю ошибку
```

Неправильное использование TODO:

```java
// TODO: исправить ошибку
```
