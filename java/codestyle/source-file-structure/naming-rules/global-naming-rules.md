# Глобальные правила именования классов, методов и переменных

Имена классов, методов и переменных должны:

- ясно передавать их назначение без необходимости изучать реализацию
- быть простыми, понятными русскоязычному программисту
- быть устоявшимися терминами предметной области

Не следует использовать редкие слова, неоднозначные сокращения и излишне абстрактные названия.

**Главный концепт хорошего имени - по имени можно понять что оно делает не открывая реализацию.**
