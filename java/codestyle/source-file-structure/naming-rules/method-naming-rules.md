# Правила именования методов

По имени метода должно быть понятно, что он делает или что возвращает.

1) Имя метода должно описывать действие или результат: `createOrder`, `calculatePrice`, `findUser`.
    1) Акцент идет на глаголы: `create..`, `calculate..`, `find..` и другие подобные в сочетании с результатом который они сделают (сделать+пользователя, посчитать+цену и т.д.)
2) Для boolean-методов использовать форму вопроса: `isActive`, `hasAccess`, `canRetry`, `shouldNotify`.
3) Для одинаковых действий использовать одинаковые глаголы по всему проекту: `findUser`, `findOrder`, `findAccount`, а не вперемешку `findUser`, `searchOrder`, `lookupAccount`.
4) Избегать слишком общих имен: `process`, `handle`, `execute` - слишком абстрактно и невозможно понять что именно делает метод и какой ждать результат (для избежания конфликтов стоит обратиться к пункту номер `1`)
