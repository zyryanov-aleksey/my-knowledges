# Правила именования методов

По имени метода должно быть понятно, что он делает или что возвращает.

- Имя метода должно описывать действие или результат: `createOrder`, `calculatePrice`, `findUser`.
- Для boolean-методов использовать форму вопроса: `isActive`, `hasAccess`, `canRetry`, `shouldNotify`.
- Для одинаковых действий использовать одинаковые глаголы по всему проекту: `findUser`, `findOrder`, `findAccount`, а не вперемешку `findUser`, `searchOrder`, `lookupAccount`.
- Избегать слишком общих имен: `process`, `handle`, `execute` - слишком абстрактно и невозможно понять что именно делает метод и какой ждать результат.
