# Организация Java-класса

Элементы класса располагаются так:

1. статические поля;
2. обычные поля;
3. конструкторы;
4. приватные методы, вызываемые из конструкторов;
5. статические фабричные методы;
6. свойства JavaBean (геттеры и сеттеры);
7. реализации методов интерфейсов;
8. приватные или защищённые шаблонные методы, вызываемые из этих реализаций;
9. остальные методы;
10. `equals`, `hashCode`, `toString`.

Private или protected методы, вызываемые из реализации метода интерфейса, ставьте непосредственно после места использования. Иными словами, при трёх реализациях интерфейса и трёх приватных методах (по одному на реализацию) порядок должен быть «реализация → её приватный метод» три раза, а не три реализации с последующими тремя приватными методами внизу. В целом организация кода должна выглядеть естественно.

Перегруженные методы и конструкторы не разделять другими членами, даже если у перегрузок различаются модификаторы.
