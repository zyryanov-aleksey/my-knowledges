# Форматирование java кода

Форматирование кода очень важная часть разработки и написания кода.
Без правильного форматирования ухудшается читаемость кода и его понимание.

Основные правила форматирования описаны в данных документах:

- Использование пустых строк для повышения читаемости [blank-lines.md](/java/codestyle/source-file-structure/code-formatting/blank-lines.md)
- Правила переносов строк (лимиты на длину строки, правила переноса и т.д.) - [line-wrapping.md](/java/codestyle/source-file-structure/code-formatting/line-wrapping.md)
- Форматирование и использование фигурных скобок - [сurly-braces-usage.md](/java/codestyle/source-file-structure/code-formatting/curly-braces-usage.md)

## Форматирование исходного кода в среде разработки

При разработке в таких инструментах как IntelliJ Idea обязательно использовать автоматическое форматирование кода 
(При использовании ИИ/Агентской разработки требуется настройка и обязательное использование Idea MCP)

Если в проекте/приложении нет своего .editorconfig, то необходимо его добавить.

Образец, который вы можете скопировать к себе, соответствующий стилю из данного руководства - [.editorconfig](/.editorconfig)
