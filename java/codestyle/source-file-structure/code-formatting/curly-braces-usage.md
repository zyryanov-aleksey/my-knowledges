# Правила использования фигурных скобок

Основные правила:

* Открывающая `{` - на той же строке, через один пробел.
* Закрывающая `}` - на отдельной строке.
* Содержимое блока - на новых строках с дополнительным отступом.
* `else`, `catch`, `finally` - на одной строке с предыдущей `}`, через пробел.
* После `}` - перенос строки, если завершён оператор, метод, конструктор или именованный класс.
* Всегда используйте фигурные скобки для `if`, `else`, `for`, `do` и `while`, даже если тело пустое или имеет один оператор

Пример корректного использования:

```java

class FormattingExample {


    @Override
    public void method() {

        for (int i = 1; i < CONST; i++) {
            if (condition()) {
                something();
            } else {
                try {
                    alternative();
                } catch (ProblemException ex) {
                    recover();
                }
            }

            if (empty()) {

            }
        }
    }


}
```
