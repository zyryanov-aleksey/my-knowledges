# Правила переноса строк

Код необходимо стараться переносить единообразно, ориентируясь на то что уже написано в других частях кода.

Правила по длине строк кода:

- Предпочтительная длина строки - 90 символов (Иногда этого можно добиться небольшой переработкой кода, иногда это невозможно).
- Жесткий лимит - 100 символов.
- Для Javadoc ориентируйтесь примерно на 80 символов, чтобы его было удобно читать в разных контекстах, например на GitHub и телефоне.

При переносе длинных выражений ориентируйтесь на 90 символов и ставьте разделители
в конце текущей строки, а не в начале следующей. Разделители: `,`, `+`, `?`, `:`, `&&`, `||`.

Пример как правильно переносить строки кода:

```java
 void myMethod() {

    if (thisLengthyMethodCall(param1, param2) &&
            anotherCheckMethodCall() &&
            yetAnotherCheckMethodCall()) {
        // ....
    }
}
```
