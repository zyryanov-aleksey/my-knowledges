# Тернарный оператор

Тернарный оператор должен использоваться если:

- условие простое и понятное
- ветки содержат короткие выражение
- результат сразу присваивается переменной

Если выражение с тернарным оператором слишком большое, то лучше переписать его на if-else для повышения читаемости кода

Правила при написании кода с тернарным оператором:

- Скобки при использовании тернарного оператора обязательны
- Проверка на `null` должна идти первой
- Не должно быть вложенных друг в друга тернарных операторов

Пример корректного использования:

```java
void exampleMethod() {

// пример 1 - правильное использование, все коротко и понятно
    String result = (value != null ? value : "default");

// пример 2 - правильно использование if-else, так как тернарный оператор получится слишком большим
    if (user != null && user.isActive()) {
        sendNotification(user);
    } else {
        logWarning();
    }
}
```

Пример некорректного использования:

```java
// в примере тернарный оператор слишком громоздкий и ухудшает читаемость,
// не рекомендуется такое использование
var result = (user != null && user.isActive()
                ? sendNotification(user)
                : logWarning()
        );
```
