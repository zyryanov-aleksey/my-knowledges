# Объявления переменных

- Объявляйте по одной переменной в строке.
- Объявляйте переменные как можно ближе к первому использованию.
- По возможности инициализируйте переменные при объявлении.
- Несколько переменных в одном объявлении допустимы только в заголовке for.

Пример:

```java
// правильно:
Order order = repository.findById(id);
int count = order.getItems().size();

// неправильно:
Order first, second;
```
