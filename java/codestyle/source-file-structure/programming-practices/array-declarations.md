# Объявление массивов и коллекций

- Объявляйте массивы и коллекции по тем же правилам, что и переменные.
- Квадратные скобки массива ставьте после типа, а не имени переменной.
- Для коллекций используйте интерфейс в качестве типа переменной, если не требуется конкретная реализация.
- По возможности указывайте тип элементов через generics.


```java
// правильно:
String[] tags = order.getTags();
List<String> names = new ArrayList<>();
Set<Long> ids = new HashSet<>();

// неправильно:
String tags[];
ArrayList names = new ArrayList();
```
