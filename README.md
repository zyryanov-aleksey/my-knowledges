### Навигация, если вы пришли самостоятельно изучить чтиво

Уже сейчас вы можете узнать:

- Как правильно давать названия вашим классам/методам/переменным (собрал лучшие практики)?
- Как правильно форматировать код, как соблюдать стиль кода везде и всегда?
- Как правильно написать код и поддержать его легкую читаемость?
- Собрал свои best-practices по использованию switch-case конструкций, тернарных операторов, объявлению переменных
- Как правильно импортировать зависимости в класс чтобы избежать путаницы и легко чинить зависимости при апгрейде?
- Добавил свои .editorconfig для автоматического форматирования на основе собственных рекомендаций и code-inspections.xml для подсветки кодсмелов и типичных ошибок в среде разработки
